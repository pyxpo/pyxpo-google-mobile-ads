# Security policy

## Supported versions

Security fixes go into the latest release of pyxpo-google-mobile-ads. Please upgrade to the newest version before you report a problem.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of
[pyxpo/pyxpo-google-mobile-ads](https://github.com/pyxpo/pyxpo-google-mobile-ads/security) and choose **Report a vulnerability**.

Please include:

- the pyxpo-google-mobile-ads and pyxpo versions, and the platform (Android, iOS, web or desktop),
- what an attacker can do, and the steps or a small app that shows it.

You get a first reply within 7 days. When the fix is released, the advisory names you as the reporter unless you ask
us not to.
